# Shaik Security Group website

Website for Shaik Security Group (Florida Lake, Roodepoort).

- `index.html`: the whole site (Home, Services, About, Contact pages, switched by the menu)
- `images/`: logo and photos

## Before going live
Replace the `[bracketed]` placeholders: Google reviews and rating, PSIRA number, office hours, areas covered, FAQ response time and the Google reviews link.

WhatsApp leads go to the number in `WA_NUMBER` near the bottom of `index.html`.
